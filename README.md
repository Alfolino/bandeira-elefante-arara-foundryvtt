# A Bandeira do Elefante e da Arara para Foundry VTT

Sistema não oficial para jogar **A Bandeira do Elefante e da Arara** no **Foundry Virtual Tabletop v14**.

Este projeto adiciona fichas de personagem, criaturas e recursos de automação pensados para facilitar partidas no universo de fantasia histórica inspirado no Brasil colonial.

## Instalação pelo Foundry

No Foundry VTT, vá em:

**Game Systems > Install System > Manifest URL**

E cole esta URL:

```txt
https://raw.githubusercontent.com/Alfolino/bandeira-elefante-arara-foundryvtt/main/system.json
```

## Recursos principais

- Ficha de personagem com visual temático.
- Controle de pontos de aprendizagem.
- Catálogo de habilidades.
- Poderes sobrenaturais com caminho, energia e rolagens.
- Combate automatizado com ataque, dificuldade, defesa e aplicação de dano.
- Ficha de criaturas e NPCs.
- Compêndio de criaturas do bestiário.
- Rolagens com modificadores de cena.
- Iniciativa integrada ao encontro do Foundry.

## Compatibilidade

- Foundry VTT v14.

## Observação

Este é um projeto de fã, feito para uso em mesa. Ele não substitui o livro oficial de regras.
